# 東泰照服勞動合作社線上人力派遣平台

這是一個可直接部署成靜態網站的照服員派遣登記平台原型，適合用於醫院護理站或病房 QR Code 張貼導流。

## 已完成內容

- 使用者登記欄位：姓名、電話、樓層、病房號碼、備註。
- 照護方案：
  - 一對六照顧 24 小時：NT$1,100
  - 一對六照顧 12 小時：NT$700
  - 一對一專人照顧 24 小時：NT$2,800
  - 一對一專人照顧 12 小時：NT$1,800
- 付款方式選擇：ATM、信用卡、LINE Pay、現場付款。
- 即時計算費用與付款提示。
- 送出後產生受理編號與登記摘要。
- 可列印的護理站 QR Code 海報。
- 管理後台 `admin.html`：查看登記資料、付款方式、付款狀態、總金額，並可更新付款狀態與匯出 CSV。
- 使用 `server.js` 啟動時，登記資料會寫入 `orders.json`，讓後台可以讀取。

## 本機預覽

可直接打開 `index.html`，或使用 Node.js 啟動本機預覽：

```powershell
node server.js 5175
```

然後開啟：

```text
http://127.0.0.1:5175/index.html
```

管理後台：

```text
http://127.0.0.1:5175/admin.html
```

## QR Code 使用方式

不要直接用 `file://` 網址製作給手機掃描，手機無法讀取電腦本機檔案。請先部署到正式網址，或使用本機預覽網址測試，再到「QR 碼連結網址」欄位填入實際要讓使用者開啟的網址。

## 正式上線前需要串接

目前付款流程是前端原型，信用卡與 LINE Pay 尚未連接實際金流。正式收款需要準備金流商戶資料，例如綠界、藍新、LINE Pay 商家帳號或合作銀行 ATM 虛擬帳號，再把付款按鈕導向實際付款 API。

正式部署到網址後，頁面中的 QR Code 會依目前網址自動產生，適合列印張貼。
